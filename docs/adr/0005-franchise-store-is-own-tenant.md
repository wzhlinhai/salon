# 加盟店是独立租户，总部通过数据授权连接，不作为上级租户

本店是加盟店，经营主体与总部不同，两方的利益和数据边界不一致。因此本店和总部各自是一个租户，顾客、卡、员工都归属本店；总部只能看到本店通过数据授权给出的数据，授权范围按数据类别设定，本店可以收回。这修订了 [ADR-0003](0003-multi-tenant-data-model-from-day-one.md) 中"老板（租户管理者）看全部门店"的假设，该假设只适用于一个老板拥有多家门店的情况。

## Considered Options

- **总部为租户管理者，本店为租户下的门店**：未被采纳。加盟商不会把全部顾客和营业数据交给总部，顾客、卡、员工归属本店更符合两方的经营关系。

## Consequences

- 卡能否在品牌内跨店使用，要在两个租户之间做结算，不能靠同一租户内的门店权限实现。P0 只允许卡在发行门店使用，跨店通用放到后期。
- 总部看数据走授权查看，不进入本店的业务操作；授权范围和收回都要留记录。
