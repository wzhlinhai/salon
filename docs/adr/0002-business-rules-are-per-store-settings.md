# 业务规则做成每家店可设置的参数，不按某一家店定制

岗位、提成、轮牌、卡项、赠送金、退卡政策、售后期限等业务规则，都做成按门店保存、可以在现场修改的设置，系统本身不写死任何一家店的做法。系统支持哪些做法，以行业里常见的做法为准（参考开源美业系统和同类产品），而不是以店主自己这家店的规则为准；店主的店只是第一家填写这些设置的店。这样系统交给另一家店时，对方可以按自己的岗位、提成和卡项重新设置，不用改代码。

## Considered Options

- **按店主这家店的真实规则定制，以后再泛化**：未被采纳。P0 就要把规则写进数据结构，以后换一家店规则不同，就要改数据结构和历史数据，代价大；而且店主自己的规则也会变。

## Consequences

- 规格里的每条业务规则都要写成"支持哪几种做法、默认是哪种"，而不是"本店怎么做"。
- 需要向店主确认的只剩无法做成设置的事实（收款账户、设备型号、现用系统的情况），不再逐条问店里的规则。
- P0 的设置清单以开源美业系统调研的"常见可配置做法"为起点（提成基数与阶梯、点客与轮牌规则、卡的扣款顺序、退卡与撤单规则等）。
- 调研中没有公开做法的项（赠送金是否计业绩、助理固定还是按比例、退卡金额算法、家庭卡）也做成设置：先给出一个默认做法，由店主在系统里选定或修改，不写死，也不做成问卷。
- 设置要按门店保存、带生效日期，改了设置不能改变已经发生的单据（下单时快照）。设置的修改要留痕（谁、何时、改前改后）。
- 支持的做法有边界：行业里没人用的做法不支持，遇到再加。
